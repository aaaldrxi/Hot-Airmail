How it opens
  1. Download the letter page below — the letter and every photo are sealed inside that one file.
  2. Open netlify.com/drop and drag the file onto it. It hands you a web address in seconds.
  3. Sign up free and claim the site. Drops nobody claims are deleted after about a day, and the code would stop working.
  4. Open the address in a private window to be sure it's really public.
  5. Paste it in the box above. The stamp repoints itself.
