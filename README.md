# 💌 Hot Air Mail — A Letter for Nikola

> A thoughtful web application designed for a long-distance relationship, allowing you to write digital letters paired with photos and package them into a nostalgic, printable airmail postcard featuring a custom QR-code "stamp."

## ✨ Features

- **Dual-Mode Opening:** Choose whether the QR code links directly to a hosted web page (supporting text + photo attachments) or contains the text directly inside the code itself.
- **Client-Side Image Processing:** Upload or drag-and-drop multiple photos; the app automatically resizes and compresses them locally in the browser before embedding them into the letter layout.
- **Perforated QR Stamp Generator:** Automatically generates a retro stamp-styled QR code that users can download as a PNG or print directly onto a physical postcard.
- **Zero Backend Required:** Written entirely in a single, self-contained HTML file containing all styles, scripts, and embedded libraries. It can be hosted instantly on static web platforms like Netlify Drop or GitHub Pages.

---

## 🛠️ Tech Stack & Architecture

- **Markup & Styling:** Semantic HTML5 and modern CSS3 featuring CSS variables, CSS grid/flexbox, and custom mask styling for the postage stamp perforations.
- **Logic:** Vanilla JavaScript (ES6+) handling state management, FileReader APIs, canvas image compression, and custom Base64 URL encoding/decoding.
- **QR Generation:** Embedded pure JavaScript QR Code generator library.
